## Platform

web

## Stack

Десктопное приложение на Electron для Windows (оболочка), окно на веб-технологиях, поэтому платформа `web`. Выбор пользователя (2026-11-02): React + TypeScript + Vite для окна, ядро на Node (TypeScript), шоу пишутся в JS/TS-файлах с тем же API, что был в Python (`show.drone(1).takeoff(100, 5)`). Старое ядро на Python и приложение на Qt остаются в репозитории как эталон для сверки и тестов, пока JS-версия не сравняется с ними.

## Users

Автор приложения и его ученики (кружок, занятия): преподаватель или увлечённый взрослый готовит шоу из 4–10 дронов LiteBee Wing и запускает его; дети и подростки пишут свои шоу и летают на занятиях. Работают в помещении, на ноутбуке с Windows, дроны на коврике с QR-кодами, рядом защитная сетка. Задача: написать шоу, проверить его в симуляции, загрузить в дроны и безопасно запустить.

## Product Purpose

Заменить Scratch-часть LiteBee Go: писать шоу кодом (а не блоками), видеть коврик сверху и свет каждого дрона во времени, проверять безопасность до запуска и запускать на настоящих дронах. Успех: человек без опыта собирает шоу, видит его в симуляции, понимает, что проверено на дроне, а что нет, и взлетает без аварий.

## Positioning

Честность о том, что проверено на живых дронах: у каждой функции есть статус «проверено на дроне» или «только симулятор», а запуск закрыт цепочкой «Проверить, Загрузить, Взвести, Старт» и красной кнопкой аварийной посадки, которая всегда на виду. Всё, кроме явных команд связи, работает без дронов. Совместим с проектами `.lbg` из LiteBee Go.

## Operating Context

- Комната не меньше 5 × 5 м, потолок выше 2 м, зрители дальше 5 м; ковёр с QR-кодами 12 × 12 клеток по 40 см (клетка = столбец + 12 × строка, клетка 0 внизу слева).
- Дроны формации (Wing FM) подключаются по Wi-Fi к роутеру `Litebee_Fm`; компьютер раздаёт адрес по UDP (порт 13146), дроны подключаются к TCP-серверу компьютера (порт 18001).
- Дрон Wing с ручным пультом: компьютер говорит с пультом по USB (COM-порт 115200, режим программирования, индикатор L4 зелёный).
- Батарея 2S 600 мАч; старт запрещён ниже 7,0 В (рекомендуется не ниже 7,4 В).
- Перед полётом: проверка, загрузка, взвод, старт; во время полёта редактор только для чтения; аварийная посадка по кнопке, Esc и при потере связи.

## Capabilities and Constraints

- Доказано на живых дронах: связь и телеметрия, калибровка, взлёт, зависание, посадка, цвет светодиода, движение по клеткам (шаг `code`, абсолютные координаты коврика), на Wing через пульт: взлёт, высота, скорость `[27,2,0,Y,X,0]` (вперёд 31 см и вправо 33 см за 2 секунды при 15 см/с).
- Не доказано: шаги `code_z`, `circle`, `circle_z` (загрузка отказывает), несколько дронов и синхронный старт, движение по клеткам без позиции, сдвиг `[30,4,X,Y]` у Wing (не работает), камера и видео.
- Позиция по коврику появляется только после короткого взлёта; без позиции миссия с движением по клеткам не стартует.
- Лимит высоты по умолчанию 150 см, настраиваемый от 20 до 200 см. Код шоу выполняется в отдельном процессе не дольше 5 секунд.
- Интерфейс на русском.

## Brand Commitments

- Название «Litebee IDE».
- Светлая чистая тема и один сдержанный акцент глубокого циана (решение пользователя 2026-10-28), без неона, свечений и тяжёлых теней.
- Дрон рисуется по фотографии настоящего LiteBee Wing пользователя: белый корпус, серые рамы из деталей-кубиков, серебристые моторы, полупрозрачные винты, без защитных колец.
- Основной шрифт Bahnschrift (идёт с Windows), цифры Consolas.

## Product Principles

1. Безопасность видна всегда: красная кнопка «Аварийная посадка» не прячется ни на одном экране, у каждого шага запуска есть причина, почему он недоступен.
2. Честно про границы: рядом с любой функцией видно, проверена ли она на дроне.
3. Коврик главный: карта и свет дронов во времени занимают центр, остальное тише.
4. Без дронов тоже полезно: писать, симулировать и проверять можно без связи.
5. Спокойный инструмент для занятий: понятно с первого раза ребёнку, надёжно взрослому, без украшательств.

## Accessibility & Inclusion

- Контраст текста не ниже 4,5:1; состояние никогда не только цветом (значок и слово).
- Всё доступно с клавиатуры (Tab по шагам запуска, Esc аварийная посадка, Ctrl+E колонка кода, F1 справочник).
- Аудитория включает детей, тексты короткие, без жаргона; ошибки говорят, что случилось и что делать.
