# Железо Wing по прошивке (образ 1.2.8) и пульт

Источник: `sys_config.fex` из `Wing_V1.2.8 FM_V1.1.2.img` (описание платы Allwinner), прошивка пульта `LiteBee Wing_remote_gd_v1.1.3.hex`, строки и импорты `pilot`, `flow`, `VideoTransmission`.
Пометки: **ПРОЧТЕНО** (в конфигурации или коде), **ВЫВОД**, **НЕИЗВЕСТНО**.

## Дрон (Allwinner, Linux 3.4-rt)

| Узел | Данные | Уверенность |
|---|---|---|
| SoC | Allwinner семейства sun8i (A33-класс), ядро `3.4.39-rt143`, имя узла `sun8i`; PMU AXP221 в конфигурации | ПРОЧТЕНО |
| Память прошивки | SPI NOR `at25df641`, 16 МБ, шина SPI0 (PC00-PC03), скорость до 50 МГц, загрузка 60 МГц | ПРОЧТЕНО |
| Wi-Fi | чип XR819 (драйверы `xradio_*`), на SDIO (`mmc1`), питание `PB03`, прерывание `PB02` | ПРОЧТЕНО |
| Камера 1 (`csi0`, передняя) | датчик `imx179` (8 Мп), MIPI 2 линии, шина TWI1, адрес 0x20, ISP включён, переворот по вертикали | ПРОЧТЕНО (совпадает с описанием «8 Мп, 88°») |
| Камера 2 (`csi1`, нижняя) | параллельный интерфейс (PE00-PE12), устройство `/dev/video1`: это камера потока, её читает `flow` (640×480, до 50 к/с) | ПРОЧТЕНО (конфигурация шины), назначение ВЫВОД |
| I²C | `twi0`: PB06/PB07; `twi1`: PE21/PE22 (там же камера 1) | ПРОЧТЕНО |
| UART | `uart0` PB08/PB09; `uart1` PG06/PG07; `uart2` PB00/PB01. Автопилот открывает `/dev/ttyS0` и `/dev/ttyS2` (чтение по 64 байта) | ПРОЧТЕНО |
| Датчики (устройства в `/dev`) | IMU: `icm_imu` или `mpu6050`; магнитометр: `hmc5883`, `ist8310`, `lis3mdl`, `mmc5883`; барометр: `dps280`, `fbm320`, `spl06`; дальномер: `ks103` (сонар), `vl53l1x` (ToF); моторы: `/dev/STM8s` (драйвер на STM8S); GPIO: `/dev/MyGpio` | ПРОЧТЕНО (список вариантов; какие стоят на Wing, ВЫВОД: по `use …` в журнале загрузки видно на живом дроне) |
| Оптический поток | вычисляется программой `flow` (закрытый алгоритм, OpenCV 3.4.1), результат в `pilot` через очередь сообщений SysV | ПРОЧТЕНО |
| Дополнительно | радио XN297L и STM32 (`xn297l stm32 link`), UWB (`uwb dmd`), GPS (`/sys/gps_power`) | ПРОЧТЕНО (поддержка в коде; ставятся ли на Wing, НЕИЗВЕСТНО) |
| Экраны, GMAC, звук и пр. | есть в общем конфиге платформы, к Wing отношения, скорее всего, не имеют | ВЫВОД |

Что отсутствует в конфиге: `gsensor`, `compass`, `battery`, `motor`, `pwm`, `led` выключены (`*_used = 0`). Значит датчики подключены не через стандартные драйверы Allwinner, а через собственные устройства (`/dev/icm_imu` и т.п.), которые создаёт ядро из образа (вшиты в ядро).

## Режим восстановления и прошивка (ПРОЧТЕНО в инструкции производителя)

* Прошивка: `PhoenixUSBPro`, образ `.img`, USB-драйвер из папки `usbdriver` (VID/PID Allwinner в режиме загрузки). Нужно зажать кнопку «烧录» (прошивка) на раме и подключить USB.
* Это режим загрузки по USB (FEL) самого чипа. Он живёт в ПЗУ SoC, а не в SPI-памяти, поэтому, как правило, переживает порчу содержимого SPI NOR (ВЫВОД по общей схеме Allwinner, на этом дроне не проверено).

## Пульт Wing (GD32E103, Cortex-M4)

* Прошивка `…remote_gd_v1.1.3.hex`: диапазон 0x08000000–0x08005ADB (около 23 КБ), вектор сброса 0x080001A9 (Thumb), вершина стека 0x20004730. Без символов.
* Строки: отладочный вывод стиков (`LH,LV,RH,RV`, `LHM,LVM,RHM,RVM` — значения и середины), положение (`y,t,r,p`), слова `moren` (вероятно «по умолчанию»). Другого текста нет.
* Прошивается через GigaDevice MCU ISP Programmer по USB (CP210x). Инструкция требует: сначала подключить пульт, потом запускать программу; после прошивки держать стики по центру при первом включении.
* Связь с дроном по радио (2,4 ГГц, XN297L на стороне дрона; ВЫВОД по коду `pilot` и `melis`), пульт отдаёт стики; режим программирования (USB): индикатор L4 зелёный.
